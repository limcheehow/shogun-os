# Email-to-Brain: Gmail Messages That Update Your Brain

Gmail inbox → brain pages. Every email from a real person creates or updates a person/company page in gbrain. Action items extracted. Signatures flagged. All via Google DWD — no OAuth popups, no token expiry.

## IMPORTANT: Instructions for the Agent

**You are the installer.** Follow these steps precisely.

**The core pattern: code for data, LLMs for judgment.**
Email collection is split into two layers:
1. **DETERMINISTIC**: code pulls emails, generates Gmail links, detects noise/signatures.
   This never fails. Links are always correct. Timestamps are always accurate.
2. **LATENT**: you (the agent) read the collected emails and make judgment calls.
   Who is important? What entities are mentioned? What action items exist?

**Do not try to pull emails yourself.** Use the collector script. It handles pagination, deduplication, Gmail link generation, and noise filtering.

## Architecture

```
Google DWD (impersonate cheehow@gotapway.com)
  ↓ Gmail API
Email Collector (deterministic Python script)
  ↓ Outputs:
  ├── brain/daily/email/messages/{YYYY-MM-DD}.json     (structured email data)
  ├── brain/daily/email/digests/{YYYY-MM-DD}.md        (markdown digest for agent)
  └── brain/daily/email/state.json                     (pagination state, known IDs)
  ↓
Agent reads digest (cron enrichment job)
  ↓ Judgment calls:
  ├── Entity detection (people, companies mentioned)
  ├── Brain page updates (timeline entries, compiled truth)
  ├── Action item extraction
  └── Priority classification (urgent / normal / noise)
```

## Opinionated Defaults

**Noise filtering (deterministic, in collector):**
- Skip: noreply@, notifications@, calendar-notification@, mailer-daemon, postmaster
- Flag: DocuSign, Dropbox Sign, HelloSign, PandaDoc (signatures needing action)
- Keep: everything else

**Digest format:** Daily markdown with sections:
- ✍️ Signatures pending (DocuSign etc. needing action)
- 📬 Messages to triage (real emails from real people)
- 🔇 Filtered noise (available if needed)

Every email gets a baked-in Gmail link: `https://mail.google.com/mail/u/0/#inbox/MESSAGE_ID` — generated by code, never by the LLM.

## Prerequisites

1. `google-dwd` recipe completed (service account key at `~/.hermes/secrets/google-dwd-sa.json`)
2. Gmail API enabled in the Google Cloud project
3. `google-api-python-client` and `google-auth` installed

## Setup Flow

### Step 1: Create the Collector Script

Write to `~/.hermes/scripts/email-collector.py`:

The collector needs these capabilities:

1. **Authenticate via DWD** — impersonate `cheehow@gotapway.com` with `gmail.readonly` scope
2. **List recent messages** — `users.messages.list` with `q=newer_than:12h` or use state tracking
3. **Get full message** — `users.messages.get` with format=metadata (headers only, not full body, to save quota)
4. **Noise filter** — deterministic substring match against known noise senders
5. **Generate Gmail link** — code-only, never LLM: `https://mail.google.com/mail/u/0/#inbox/{id}`
6. **State tracking** — store known message IDs in `state.json` for dedup
7. **Write digest** — daily markdown with sections

```python
#!/usr/bin/env python3
"""Email Collector — DWD variant. Deterministic Gmail → brain."""
import os, json, sys
from datetime import datetime, timezone
from google.oauth2 import service_account
import google.auth.transport.requests
from googleapiclient.discovery import build

# ── Config ──────────────────────────────────
SA_PATH = os.path.expanduser("~/.hermes/secrets/google-dwd-sa.json")
SUBJECT = "cheehow@gotapway.com"
SCOPES = ["https://www.googleapis.com/auth/gmail.readonly"]
DATA_DIR = os.path.expanduser("~/brain/daily/email")
STATE_FILE = os.path.join(DATA_DIR, "state.json")
MAX_RESULTS = 50

NOISE_SENDERS = [
    "noreply", "no-reply", "notifications@", "calendar-notification",
    "mailer-daemon", "postmaster", "donotreply",
]
SIGNATURE_PATTERNS = ["docusign", "dropbox sign", "hellosign", "pandadoc",
    "please sign", "signature needed"]

# ── Auth ────────────────────────────────────
creds = service_account.Credentials.from_service_account_file(
    SA_PATH, scopes=SCOPES, subject=SUBJECT
)
creds.refresh(google.auth.transport.requests.Request())
service = build("gmail", "v1", credentials=creds)

# ── State ────────────────────────────────────
os.makedirs(f"{DATA_DIR}/messages", exist_ok=True)
os.makedirs(f"{DATA_DIR}/digests", exist_ok=True)
state = {"known_ids": [], "last_collect": None}
if os.path.exists(STATE_FILE):
    with open(STATE_FILE) as f:
        state = json.load(f)

today = datetime.now(timezone.utc).strftime("%Y-%m-%d")
since = state.get("last_collect", today)

# ── Collect ──────────────────────────────────
query = f"newer_than:24h"  # conservative window
messages = []
page_token = None

while True:
    results = service.users().messages().list(
        userId="me", q=query, maxResults=MAX_RESULTS,
        pageToken=page_token
    ).execute()
    for msg in results.get("messages", []):
        if msg["id"] not in state["known_ids"]:
            messages.append(msg)
    page_token = results.get("nextPageToken")
    if not page_token:
        break

# ── Enrich + Categorize ──────────────────────
def get_message(msg_id):
    return service.users().messages().get(
        userId="me", id=msg_id, format="metadata",
        metadataHeaders=["From", "Subject", "Date", "To"]
    ).execute()

triage, signatures, noise = [], [], []

for msg in messages:
    full = get_message(msg["id"])
    headers = {h["name"]: h["value"] for h in full.get("payload", {}).get("headers", [])}
    sender = headers.get("From", "unknown").lower()
    subject = headers.get("Subject", "")
    gmail_link = f"https://mail.google.com/mail/u/0/#inbox/{msg['id']}"

    entry = {
        "id": msg["id"],
        "from": headers.get("From", ""),
        "subject": subject,
        "date": headers.get("Date", ""),
        "link": gmail_link,
    }

    if any(n in sender for n in NOISE_SENDERS):
        noise.append(entry)
    elif any(p in subject.lower() or p in sender for p in SIGNATURE_PATTERNS):
        signatures.append(entry)
    else:
        triage.append(entry)

# ── Persist ──────────────────────────────────
msg_file = f"{DATA_DIR}/messages/{today}.json"
with open(msg_file, "w") as f:
    json.dump({"triage": triage, "signatures": signatures, "noise": noise}, f, indent=2)

# ── Digest ───────────────────────────────────
digest = f"# Email Digest — {today}\n\n"
if signatures:
    digest += "## ✍️ Signatures Pending\n\n"
    for e in signatures:
        digest += f"- **{e['from']}** — {e['subject']}  \n  {e['link']}\n"
    digest += "\n"
if triage:
    digest += "## 📬 Messages to Triage\n\n"
    for e in triage:
        digest += f"- **{e['from']}** — {e['subject']}  \n  {e['link']}\n"
    digest += "\n"
if noise:
    digest += f"## 🔇 Filtered Noise ({len(noise)})\n\n"

digest_file = f"{DATA_DIR}/digests/{today}.md"
with open(digest_file, "w") as f:
    f.write(digest)

# ── Update state ─────────────────────────────
state["known_ids"].extend([m["id"] for m in messages])
state["last_collect"] = today
with open(STATE_FILE, "w") as f:
    json.dump(state, f)

print(f"Collected {len(triage)} triage, {len(signatures)} signatures, {len(noise)} noise")
```


### Step 3: Create the Cron Jobs

Two crons in the **default** profile:

**Collector** (every 30 min — deterministic, no LLM):
```bash
hermes cron create \
  --name "Email Collector" \
  --schedule "*/30 * * * *" \
  --script email-collector.py \
  --no-agent \
  --deliver local
```

**Enrichment** (3x/day — agent reads digest + updates brain pages):
```bash
hermes cron create \
  --name "Email Enrichment" \
  --schedule "0 9,13,17 * * 1-5" \
  --prompt "$(cat <<'PROMPT'
## Email Enrichment — Read Digest, Update Brain Pages

Read the latest email digest at ~/brain/daily/email/digests/$(date +%Y-%m-%d).md

For each message in the "Messages to Triage" section:
1. Extract sender name and company from the email address
2. Search gbrain for the person: gbrain search "sender name"
3. If a person page exists, add a timeline entry:
   - YYYY-MM-DD | Email from {name}: {subject} [Source: Gmail]
4. If the person is notable (client, partner, vendor) and has no page, create one
5. For "Signatures Pending" — flag any that have been pending more than 24h

Deliver a brief summary: "Processed N emails. Updated M person pages. X signatures pending >24h."
PROMPT
)" \
  --skills "gbrain-operations" \
  --enabled-toolsets "terminal,file,search" \
  --deliver origin
```

## Troubleshooting

| Problem | Fix |
|---------|-----|
| No emails collected | Check DWD auth: run the token verify from `google-dwd` recipe. Check `newer_than` query window. |
| Gmail links don't work | The `u/0` parameter assumes primary account. Change to `u/1` if you have multiple accounts. |
| Digest is empty | All emails might be noise — check noise filter rules. Check `state.json` — the first run may have already collected them. |
| Collector misses emails | Gmail API `list` returns up to 500. If you get >500 emails in 24h, implement pagination with `nextPageToken`. |
