# Bukku — Accounting Provider Setup

> **Malaysian cloud accounting software.** Suitable for SMEs, supports sales invoices, purchase bills, contacts, and products.
> Implements the [CONTRACT.md](CONTRACT.md) standard tools via the unified bridge.

## Setup

### 1. Get API Credentials

1. Log in to your Bukku web app at `https://<your-subdomain>.bukku.my`
2. Go to **Control Panel → Integrations → API Access**
3. Generate an access token (Bearer token)
4. Note your company **subdomain** (e.g., `raubensdnbhd`)

### 2. Configure the MCP Server

```yaml
mcp_servers:
  accounting:
    command: python3
    args: [~/.hermes/scripts/acct-bridge.py]
    env:
      ACCT_PROVIDER: "bukku"
      ACCT_API_KEY: "${ACCT_API_KEY}"
      ACCT_SUBDOMAIN: "${ACCT_SUBDOMAIN}"
```

### 3. Set Environment Variables

```bash
# In the profile's .env (e.g., ~/.hermes/profiles/finance-manager/.env)
ACCT_PROVIDER=bukku
ACCT_API_KEY=your-bukku-bearer-token
ACCT_SUBDOMAIN=your-company-subdomain
```

### 4. Verify

```bash
echo '{"id":1,"method":"tools/call","params":{"name":"acct_list_contacts","arguments":{"limit":5}}}' \
  | python3 ~/.hermes/scripts/acct-bridge.py
# Expected: JSON with contacts list
```

## Notes

- Bukku uses Bearer token auth with `Company-Subdomain` header
- The `number` field is auto-generated by Bukku (IV-YYMM/xxx pattern)
- For credit sales, `term_items` is required (use `term_id: 1` for COD)
- For cash sales, use `deposit_items` instead of `term_items` and `payment_mode: "cash"`
- The PATCH endpoint only accepts `status` changes — other fields cannot be modified after creation
